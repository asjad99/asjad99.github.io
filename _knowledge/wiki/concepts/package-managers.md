# Package managers

Installers for tools and libraries. System level: Homebrew (`brew`). Node: `nvm` (versions), `npm`, `pnpm` via
`corepack`. Python: `pip` (call as `python3 -m pip`), `uv` (fast). Many install via `curl … | bash`; only run
scripts from trusted, official pages.
