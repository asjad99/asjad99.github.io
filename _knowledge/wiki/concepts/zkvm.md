# zkVM (zero-knowledge virtual machine)

A zkVM is a computer that produces a [[zero-knowledge-proofs|zero-knowledge proof]] for any program it runs.
Programmers write normal code (e.g. Rust) instead of hand-building cryptographic "circuits".

## Key points
- Before zkVMs, each task needed specialists to write custom circuits, taking months or years (src-0002, vendor claim).
- Uma Roy calls SP1 "like a foundation model for cryptography": one general machine, many jobs (src-0001).
- Speed race largely won by 2025–26; focus is shifting to security and formal verification.
